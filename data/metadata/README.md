# Metadatos de los casos

Cada caso incorporado al libro registra su procedencia en un archivo `case-*.yml`
basado en `resources/templates/dataset-metadata.yml`.

El archivo debe completarse antes de descargar o procesar datos y actualizarse
si cambia la versión docente. Los datos de terceros conservan su licencia
original; la licencia del libro no modifica los permisos de redistribución. Los
objetos provistos por paquetes se cargan desde el paquete y no se duplican en
`data/raw/`.
